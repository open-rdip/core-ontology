## CQ1: What software (and version) was used in each research activity?

```sparql
PREFIX rdip: <https://w3id.org/rdip/>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>

SELECT ?project ?projectTitle ?activity ?actTitle ?software ?swTitle ?version
WHERE {
  ?project rdip:hasActivity ?activity .
  ?activity rdip:usedSoftware ?software .
  OPTIONAL { ?project  rdip:title ?projectTitle . }
  OPTIONAL { ?activity rdip:title ?actTitle . }
  OPTIONAL { ?software rdip:title ?swTitle . }
  OPTIONAL { ?software rdip:version ?version . }
}
ORDER BY ?project ?activity
```

**Tests:** Software–Activity linkage (rdip:usedSoftware)

## CQ2: What is the ordered sequence of typed activities in each project?

```sparql
PREFIX rdip: <https://w3id.org/rdip/>
PREFIX rdf:  <http://www.w3.org/1999/02/22-rdf-syntax-ns#>

SELECT ?project ?projectTitle ?activity ?actTitle ?actType ?nextAct ?nextTitle
WHERE {
  ?project rdip:hasActivity ?activity .
  ?activity a ?actType .
  FILTER(?actType IN (
    rdip:DataCollectionActivity, rdip:DataProcessingActivity,
    rdip:DataProductionActivity, rdip:DataAnalysisActivity,
    rdip:SoftwareDevelopmentActivity
  ))
  OPTIONAL { ?project  rdip:title ?projectTitle . }
  OPTIONAL { ?activity rdip:title ?actTitle . }
  OPTIONAL {
    ?nextAct rdip:follows ?activity .
    ?nextAct rdip:title ?nextTitle .
  }
}
ORDER BY ?project ?actType
```

**Tests:** Activity typing + ordering (rdip:follows)

## CQ3: Which people participated in each project?

```sparql
PREFIX rdip: <https://w3id.org/rdip/>
PREFIX vivo: <http://vivoweb.org/ontology/core#>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>

SELECT ?project ?projectTitle ?person ?personName
WHERE {
  ?project rdip:hasParticipant ?person .
  ?person a vivo:Person .
  OPTIONAL { ?project rdip:title ?projectTitle . }
  OPTIONAL { ?person  rdfs:label ?personName . }
}
ORDER BY ?project ?personName
```

**Tests:** Person–Project linkage (rdip:hasParticipant)

## CQ4: Which datasets were used or produced by each activity?

```sparql
PREFIX rdip: <https://w3id.org/rdip/>
PREFIX dcat: <http://www.w3.org/ns/dcat#>

SELECT ?project ?projectTitle ?activity ?actTitle ?usedDS ?usedTitle ?prodDS ?prodTitle
WHERE {
  ?project rdip:hasActivity ?activity .
  OPTIONAL { ?project  rdip:title ?projectTitle . }
  OPTIONAL { ?activity rdip:title ?actTitle . }
  OPTIONAL {
    ?activity rdip:usedDataset ?usedDS .
    ?usedDS rdip:title ?usedTitle .
  }
  OPTIONAL {
    ?activity rdip:generatesDataset ?prodDS .
    ?prodDS rdip:title ?prodTitle .
  }
  FILTER(BOUND(?usedDS) || BOUND(?prodDS))
}
ORDER BY ?project ?activity
```

**Tests:** Dataset–Activity linkage (rdip:usedDataset, rdip:generatesDataset)

## CQ7: What hyperparameters and random seeds were used in each activity?

```sparql
PREFIX rdip: <https://w3id.org/rdip/>

SELECT ?project ?projectTitle ?activity ?actTitle ?paramName ?paramValue ?paramType ?isSeed
WHERE {
  ?project rdip:hasActivity ?activity .
  ?activity rdip:hasParameter ?param .
  OPTIONAL { ?project  rdip:title ?projectTitle . }
  OPTIONAL { ?activity rdip:title ?actTitle . }
  OPTIONAL { ?param rdip:parameterName ?paramName . }
  OPTIONAL { ?param rdip:parameterValue ?paramValue . }
  OPTIONAL { ?param rdip:parameterDataType ?paramType . }
  BIND(EXISTS { ?param a rdip:RandomSeed } AS ?isSeed)
}
ORDER BY ?project ?activity DESC(?isSeed) ?paramName
```

**Tests:** Parameter–Activity linkage (rdip:hasParameter), RandomSeed subclass

## CQ8: What computing environment was used for each activity?

```sparql
PREFIX rdip: <https://w3id.org/rdip/>

SELECT ?project ?projectTitle ?activity ?actTitle ?os ?gpu ?cuda ?ram
WHERE {
  ?project rdip:hasActivity ?activity .
  ?activity rdip:executedIn ?env .
  OPTIONAL { ?project  rdip:title ?projectTitle . }
  OPTIONAL { ?activity rdip:title ?actTitle . }
  OPTIONAL { ?env rdip:osVersion ?os . }
  OPTIONAL { ?env rdip:gpuModel ?gpu . }
  OPTIONAL { ?env rdip:cudaVersion ?cuda . }
  OPTIONAL { ?env rdip:hardwareSpec ?ram . }
}
ORDER BY ?project ?activity
```

**Tests:** Environment–Activity linkage (rdip:executedIn)

## CQ9: What evaluation results were produced, on which dataset split?

```sparql

SELECT ?project ?projectTitle ?activity ?actTitle ?metric ?value ?split ?evalDataset
WHERE {

  OPTIONAL { ?result rdip:metricName ?metric . }
  OPTIONAL { ?result rdip:metricValue ?value . }
  OPTIONAL { ?result rdip:splitLabel ?split . }
  OPTIONAL { ?result rdip:evaluationDataset ?evalDataset . }
}
ORDER BY ?project ?metric
```

**Tests:** EvaluationResult–Activity linkage (rdip:generatesResult)

## CQ10: What is the derivation lineage of each dataset?

```sparql
PREFIX rdip: <https://w3id.org/rdip/>
PREFIX dcat: <http://www.w3.org/ns/dcat#>

SELECT ?derived ?derivedTitle ?source ?sourceTitle
WHERE {
  ?derived a dcat:Dataset ;
           rdip:derivedFrom ?source .
  OPTIONAL { ?derived rdip:title ?derivedTitle . }
  OPTIONAL { ?source  rdip:title ?sourceTitle . }
}
ORDER BY ?derived
```

**Tests:** Dataset derivation chains (rdip:derivedFrom)
